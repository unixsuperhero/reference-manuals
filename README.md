
# Reference Manuals

I often have ai generate markdown docs that will cover a subject completely and
offer various improvements over existing docs.

# Key Markdown Files

- **./index.md** - Acts as a Table of Contents.  Should link to most, if not all
  other manuals.
- **./docs/<DOC>.md** - each individual doc
- **./export/** - Location of docs that have been converted/exported to other
    formats.
